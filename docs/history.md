# История версий и решений

## Отправная точка: статья «The Omission Bug»

Диагноз из статьи: агент проходит все проверки, но пропускает суть. Частный случай в нашей
системе скиллов: агент открывает скилл, отвечает «учту» и работает как будто скилла нет.
Причины: декларация дешевле действия, у нарушения нет цены. Вывод: дисциплину агентов
промптами не построить, нужны механические шлагбаумы.

## v0.1 (октябрь 2026): proof-of-concept

Файл: `src/skill-gate.ts` в первом коммите (`4425693`).

Вопрос был один: умеет ли вообще OMP блокировать вызов инструмента расширением.
Прототип подключался флагом `-e`, режимы через env: `SKILLGATE=block|nudge|off`.
Отдельно решена дыра дизайна: если блокировать всё, агент не сможет выполнить
требование гейта (сам `read skill://`), поэтому чтение скиллов пропускалось всегда.
Ответ: да, `ToolCallEventResult` умеет `{ block: true, reason }`.

## v1.0 (19-20 октября 2026): публичный релиз слоя 1

Коммиты `5993569`. Опубликовано: [ai4bordon/omp-skill-gate](https://github.com/ai4bordon/omp-skill-gate).

Механика:

- до первого действия в ходе: открыть скилл (`read skill://<имя>`) или декларировать
  «скиллов нет - причина»;
- блокировка любых gated-инструментов (edit, write, bash, read, grep, glob, find, eval,
  web_search, task) и всех MCP-инструментов до выполнения требования;
- после хода: сводка в чат: блоки, скиллы, декларации, штраф за «невымытый» ход;
- командный интерфейс `/skill-gate` для статуса.

Решение v1.0, которое сохранилось до сих пор: блокировать и «безобидные» read/grep,
потому что работа без скилла начинается именно с них.

## v5.0/v5.1 (22 октября 2026): слой 2, обязательства из SKILL.md

Коммит `3008cee`. Спецификация: `specs/` (волны 1-6). Это главный скачок системы.

Ключевые решения:

- **Обязательства берутся из самого скилла, а не из ручной таблицы.** Первая попытка
  (в wave 1 спеки) была таблицей `skill-obligations.json`, которую надо вести руками;
  она умерла как мёртвый код. Вместо неё `extractObligations()`: чек-листы `- [ ]`
  и нумерованные шаги из секций процесса. Покрытие реального каталога: 93 из 118 скиллов
  сразу, домен не важен.
- **Статус обязателен по каждому пункту**: сделано / неприменимо / не сделано.
  Честный пробел принимается: гейт, который учит врать («перепиши как сделано»),
  опаснее гейта, который требует признаться.
- **Доказательство проверяется по журналу хода**: путь, команда или цитата.
  Чтение файла до правки = внешнее доказательство, запись без чтения = своё
  (подтверждает существование, не качество).
- **`session_stop`, а не `agent_end`**: блок завершения хода с полным списком
  «без статуса» и «без подтверждения». `agent_end` остался для сводки, он notification-only.
- **Предохранитель**: три отказа, дальше ход пропускается с пометкой «НЕ ПРИНЯТО».
  Без него зависший цикл мог длиться вечно.

## v5.2 (23 октября 2026): правки по результатам стенда

Коммит `2ffcf7d`. Стенд `bench/` прогнал 20 промптов и нашёл шесть дефектов:

| # | Дефект | Правка |
|---|---|---|
| 1 | маркер списка `- ` перед «сделано:» ломал разбор | маркер разрешён в регулярке |
| 2 | форма `сделано: скилл [o1]` не разбиралась (два скилла, id сталкиваются) | ключ `скилл:oN` |
| 3 | обязательства вытягивались из `references/` (шкала состояний pohuy как работа) | только тело скилла: `isSkillBody` |
| 4 | 5 скиллов давали 30 строк статусов | TOTAL_OBLIGATION_CAP = 10 поверх 6 на скилл |
| 5 | доказательство-цитата без метки «цитата:» не принималось | фрагмент в кавычках ищется в накопленных выводах инструментов |
| 6 | самоподтверждение: доказательство из собственного ответа | строки статуса вычитаются из области поиска |

Каждая правка прикрыта пробой: `rx-fix-test.ts` (9/9), `ref-check.ts` (2/2), `quote-test.ts` (2/2).

## Советник (v6, 22 октября 2026): смысловой ревьюер

`advisor/WATCHDOG.md`, `advisor/WATCHDOG.yml`. Подробности: `docs/advisor.md`.

Решение, продиктованное замером: jev как выборщик скиллов дал 77% точности на 65 промптах,
поэтому выбор скилла оставлен агенту, а модель подключена там, где детерминизм невозможен:
смысловая проверка. Советник не блокирует, только замечания, и его зона отделена от гейта.
