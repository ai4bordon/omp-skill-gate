# Стенд: методика и результаты

Стенд: 20 промптов, 18 доменов + 2 контрольных. Цель: проверить систему целиком,
не в лабораторных условиях: агент приходит в чистый каталог с заготовкой и работает
как в жизни.

## Состав

- `prompts.tsv`: промпт и ожидаемый скилл на строку. Домены: код+TDD, ревью кода,
  спека, лендинг, дизайн-док, ресёрч, README, Telegram Mini App, PowerShell, bats,
  MCP-сервер, память, вики, дебаг, рефакторинг god-файла, аудит секретов, коммит,
  презентация. Контрольные: «объясни HTTP/2 vs HTTP/3» (скилл не нужен, проверяем
  честность «скиллов нет») и «переименуй переменную» (тривиальная правка).
- `seed.py`: фикстуры на 22 файла (js, ps1, sh, config, README, god-файл 421 строка,
  git-репо с непроиндексированной правкой).
- `run.py`: параллельные прогоны `omp -p --advisor <промпт> --mode json`, stdout прямо
  в файл, таймаут 1200 с, воркеров 5.
- `parse.py`: разбор вывода в таблицу и summary.json.
- `from_journal.py`: те же данные из журналов сессий (`~/.omp/profiles/<профиль>/agent/sessions/`),
  выбор сессии по метке времени в имени.
- `compare.py`: сравнение двух сводок.
- `reset.py`: пересоздание каталогов прогонов.

Три прохода: до правок гейта, после правки парсера статусов, после правки доказательств.

## Результаты

| Метрика | Проход 1 | Проход 2 | Проход 3 (8 перегнанных) |
|---|---|---|---|
| Выбор скилла | 20/20 в пределах групп синонимов | 20/20 | 8/8 |
| Блоки гейта на прогон | ~2.5 | ~2 | 0-1 |
| Ходов на прогон | 27 | 25 | 13 |
| Замечаний Советника | 30 | 24 | 5 |
| Статусы принимаются | с 3-4 попытки | со 2-3 | с первой |

Сводки: `results/pass{1,2,3}-summary.json`. Проход 3 перегонял только 8 прогонов:
5 ночных умерли по сетевому сбою (connection refused к API-провайдеру, 10 авторетраев)
и были перегнаны утром на той же версии гейта.

Группы синонимов: каталог скиллов перекрывается (tdd-workflow / test-driven-development,
frontend-design / design-taste-frontend и т.п.), поэтому верным считается любой скилл
группы. pohuy (загружаемый всегда по инструкции владельца) не считается выбором.

## Наблюдения вне системы

- Дорогие задачи дороги не из-за гейта: лендинг с генерацией изображений 167 ходов
  (23 скриншота), Telegram Mini App 108 ходов (цикл «сделал → скриншот → переделал»).
  Это кандидат на отдельный потолок итераций, к скиллам отношения не имеет.
- Смена модели по умолчанию между окнами прогонов: 3 дешёвых прогона на
  deepseek-v4.1-flash-1017, 5 вечерних на glm-5.3. «Цена выросла в 16 раз» оказалась
  артефактом тарифа: в сопоставимых тарифах $0.45 (проход 2) против $0.47 (проход 3)
  на 8 прогонов. Урок: при сравнении прогонов фиксируйте модель.
- Советник в проходе 1 сам нашёл дефект парсера гейта раньше разработчика
  (24 из 30 замечаний про шум гейта). После правок гейта замечания стали только
  содержательными.

## Воспроизведение

```bash
cd bench
python seed.py        # создать каталоги прогонов с фикстурами
python run.py         # прогнать 20 промптов (нужен omp с профилем, где стоит гейт)
python parse.py results
```

Прогоны пишутся в `results/<id>.json` (jsonl-выход omp), сводные данные в summary.
Живой прогон требует API-ключ модели: это единственный сетевой шаг, всё остальное
(пробы расширения) работает без сети.

## Порядок запуска прогонов

Требования: omp с профилем, в котором стоит `src/skill-gate.ts`, настроенный Советник
(`--advisor`), модель с API-ключом. run.py поднимает до 5 параллельных сессий;
таймаут 1200 с на прогон.
