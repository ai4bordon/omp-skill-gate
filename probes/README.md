# Пробы расширения

Запускаются локально, без сети и без модели: расширение подключается к фейковому `pi`,
события подаются напрямую.

```
bun obligations-test.ts   # 13/13: извлечение, статусы, доказательства, предохранитель
bun quote-test.ts         # 2/2: цитаты из вывода инструментов
bun rx-fix-test.ts        # 9/9: разбор строк статуса
bun ref-check.ts          # 2/2: тело скилла vs references/
bun mass-check.ts <каталог-скиллов>   # покрытие каталога обязательствами
```
